# Ink & Insight

A responsive, multi-page blog application interface built with semantic HTML, modern CSS, and vanilla JavaScript.

## Pages

- **Home** (`index.html`) — Hero section, curated stories, and newsletter signup
- **Login** (`login.html`) — Accessible sign-in form with password visibility toggle
- **Register** (`register.html`) — Account creation form
- **Dashboard** (`dashboard.html`) — Personalized feed, topic filters, reading list, and trending stories
- **Create Blog** (`create-blog.html`) — Minimal writing editor with topic selection

## Run locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Tech

- Semantic HTML5
- Responsive CSS with mobile breakpoint
- Vanilla JavaScript for navigation, form interactions, and editor feedback
- Google Fonts: DM Sans and Playfair Display
